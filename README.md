# Crank & Combustion

ボア・ストローク・気筒数から燃焼圧と排気脈動を実時間で解き、そのまま音にするブラウザ用エンジンシミュレータ。
組んだエンジンでコーナーのあるコースを 2〜13 台で走らせることもできます。
レースは物理性能だけで競う「リアル」と、ブレーキングで充電したBOOSTを終盤に使う「レースバトル」を選べます。
レースバトルでは各車に「逃げ・先行・差し・追込」の作戦を指定でき、差し・追込は序盤に出力を温存して終盤の直線で追い上げます。
レース画面は台数に合わせて縦に広がり、名前は各車の三角マーカーに表示されます。多台数の密集時は名前を安定した順序で自動的にずらし、その位置をレース中固定したまま車に追従します。完全な名前は順位表にも表示します。
さらに8項目の組み合わせを「高回転NA・トルクチューン・軽量レスポンス・多気筒ハーモニー」として評価し、相性が良いエンジンほどBOOSTの充電量と出力が上がります。

**公開先 → https://kou114w.github.io/engine/**

ファイルは 2 つだけで、ビルドもサーバー処理も要りません。

| ファイル | 役割 |
|---|---|
| `index.html` | 本体。これ 1 つで動きます |
| `garage.json` | 公開ボード。置いておくと全員の画面に同じ番号とランキングが出ます |

## 何ができるか

- **8 項目でエンジンを組む** — 排気量・気筒数・圧縮比・燃焼室形状・吸排気・バルブタイミング・空燃比・点火時期。
  シリンダー配置（直列 / V型 / 水平対向）とバンク角も選べます
- **設定が音を大きく変える** — 排気管・集合管・吸気管の寸法、消音量、排気ガス温度（＝管内音速）まで
  8 項目から決まります。直管と純正マフラーでは音量そのものが約 2 倍違います
- **項目ごとの 4 桁ロック** — 各設定に個別の暗証番号をかけられます（詳細は下記）
- **ダイナモ計測** — 同じ物理モデルを高速で回してトルク・出力曲線を出します
- **対戦** — 普段は隠れています。出し方は下記

## 対戦パネルの出し方

普段は表示されません。次のいずれかで出ます。

- ページ上で `r` `a` `c` `e` とタイプする（入力欄にカーソルが無いとき）
- 左上のタイトルを素早く 5 回タップ（スマホ向け）
- 対戦リンク（`#a=…&b=…`）を開く

もう一度同じ操作をすると引っ込みます。ページを開き直すとまた隠れます。

コースは直線 3 種（402 m / 201 m / 1000 m）と、コーナーのある 9 種です。
峠は低速型 1.3 km、高速ワインディング 1.8 km、連続ヘアピン 1.3 km、
高低速を混ぜたロング 2.5 kmから選べます。
ラリーは高速グラベル 2.1 km、低速林道 1.4 km、舗装とグラベルが切り替わるミックス 2.7 kmの3種です。
コーナーではタイヤのグリップを摩擦円として前後と横で取り合うので、
立ち上がりでトルクを出しすぎればホイールスピンし、足りなければ加速しません。
グラベルと林道は区間ごとにグリップと転がり抵抗が変化し、舗装路より制動距離が伸び、立ち上がりでホイールスピンしやすくなります。
直線性能が高いエンジンほど駆動系・冷却・タイヤへの負担が増えるため、カーブでは旋回・制動・立ち上がりのグリップが低下します。
低下量は舗装路のカーブで最大30%、グラベルや林道では最大55%です。直線コースにはこの補正が入らないため、最高速型はドラッグ、軽快なエンジンは峠やラリーで強みを出せます。

各レーンの「作戦」で `逃げ` / `先行` / `差し` / `追込` を選べます。
`差し` と `追込` は序盤のスロットルを抑えてBOOSTを温存し、コース後半から仕掛けます。
`自動` は排気量・回転上限・ボア／ストローク比から、そのエンジンに合う作戦を選びます。
各レーンのエンジン情報には `BOOST相性` が表示され、レース結果には発動したセッティング名と相性率が表示されます。
作戦は対戦リンクにも保存されます。「リアル」では作戦補助とBOOSTは働きません。

## 対戦相手とエンジンを共有する

**リンクを送る**（推奨・アカウント不要）
対戦パネルで「対戦リンクをコピー」。URL にエンジンの設定そのものが入るので、
受け取った人が開くと同じ組み合わせがセットされ、対戦パネルも自動で出ます。

**8 桁の番号**
「番号を発行」の作戦欄で「自動・逃げ・先行・差し・追込」を選んでから発行します。
新しい番号は `4`〜`8` から始まり、主要設定と作戦を番号自体に圧縮しているため、
サーバーもアカウントもファイル交換も不要で、別のスマホや PC から読み込めます。
画面に出す共有形式は8桁番号に統一しています。
レース欄へ番号を入れると作戦欄も自動で切り替わります。従来の `9` から始まる番号は
「作戦：自動」として、旧形式の端末保存番号と `garage.json` の公開番号も引き続き読めます。

## 設定のロックについて

各設定に 4 桁の暗証番号をかけられます。初期状態では全項目がロックされた状態で配布されています。

**これは暗号ではありません。** ページは全部ブラウザの中で動き、4 桁は 1 万通りしかなく、
照合に使うハッシュ関数も `index.html` の中にあります。読める人には割れます。
うっかり動かすのを防ぐ掛け金であって、鍵ではありません。
初期状態の暗証番号はこの README には載せていません。

## 公開ボードを更新する

`garage.json` を書き換えてコミットすると、全員の画面に反映されます。

1. ページ下部の「ガレージを書き出し」で `garage.json` を作る
2. その中の `rows` と `numbers` を、リポジトリの `garage.json` に足す
3. コミットして push

```json
{
  "kind": "crank-and-combustion-garage",
  "v": 2,
  "rows": [
    { "id": "一意な文字列", "name": "表示名", "code": "E4-…",
      "veh": "gt", "course": "drag402", "dist": 402.336, "et": 13.2, "trap": 179, "at": 0 }
  ],
  "numbers": { "10000001": { "code": "E4-…", "engine": "V8 90° · 5.00L", "at": 0 } }
}
```

`veh` は `gt` / `light` / `muscle` / `bike`、
`course` は `drag402` / `drag201` / `drag1k` / `sprint` / `circuit` / `pass`。
同じ `veh` と `course` の記録どうしが 1 つのランキングになります。
`course` の無い古い記録は距離から直線コースに振り分けられます。

`et` は各自の申告値です。「挑戦」を押すと、相手のエンジンを手元で走らせ直して勝負します。

## 更新のしかた

```bash
git add -A && git commit -m "update" && git push
```

Pages は `main` ブランチの `/ (root)` から配信する設定で、すでに有効になっています。
push から 1〜2 分で反映されます。

## 動作条件

- 音声には Web Audio を使います。音が出ないときは端末のマナーモードを確認してください
- 3D 表示のみ CDN から three.js を読み込むため、オフラインでは 2D 断面にフォールバックします
- 設定のロックと記録の保存に localStorage を使います。プライベートウィンドウでは保持されません
